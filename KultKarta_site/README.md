# КультКарта Москвы

Учебный проект по дисциплине «Культура личности и общества», группа ОБ26-30.
Сайт свёрстан на HTML и CSS.

## Структура

| Файл / папка | Что это |
|---|---|
| `index.html`, `catalog.html`, `afisha.html`, `lichnost.html`, `team.html` | страницы сайта (собираются автоматически) |
| `style.css` | общий файл стилей |
| `img/` | фото мест: `01.jpg` … `13.jpg` (номер = номер карточки) |
| `generator/build.py` | сборка страниц: тексты карточек и разделов меняются здесь |
| `generator/fetch_events.py` | загрузка ближайших событий из открытого API KudaGo |
| `.github/workflows/update-afisha.yml` | расписание: каждый день в 06:00 МСК |

## Как работает ежедневное обновление

1. В 06:00 по Москве GitHub Actions запускает `fetch_events.py`: он берёт события на 14 дней вперёд для каждого места из каталога.
2. `build.py` пересобирает страницы: афиша, блок «Скоро в городе» на главной и «Ближайшие события» в карточках.
3. Изменения сохраняются в репозиторий, Render видит новый коммит и обновляет сайт.

Если источник не ответил, файлы не меняются и на сайте остаётся последняя удачная афиша.

Запустить вручную: вкладка **Actions** → «Ежедневное обновление афиши» → **Run workflow**.

## Как менять тексты

Тексты карточек, маршрутов и разделов лежат в `generator/build.py`. После правки выполните `python generator/build.py` или дождитесь утреннего запуска.
